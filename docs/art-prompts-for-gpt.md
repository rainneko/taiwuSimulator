# GPT 图像生成工作流程与 Prompt 清单

> **视觉方向：80% papertrails 纸模立体感 + 20% 水墨古风**
> 本文档包含完整的 GPT 出图流程，不只是 prompt——参考图是出图质量的关键。
> 原版已有的美术素材（战斗背景、地形图标、角色 Spine 等）从游戏文件提取，不用 AI 生成。

---

## 第零步：建立风格基线（每次新开 GPT 对话必做）

> 上一轮只靠文字 prompt 出的 8 张图风格不对。根本原因是 GPT 没有见过目标风格的参考图。

**必须在出任何 prompt 之前完成以下步骤：**

### 0.1 给 GPT 看 papertrails 参考

先把下面三张截图**直接上传**给 GPT（GPT 不一定能打开 GitHub 链接，所以必须上传图片文件）：

- `screenshots/hero.png` — 纸模世界全景（来自 https://github.com/xikhar/papertrails）
- `screenshots/village.png` — 白天村庄
- `screenshots/village-night.png` — 夜晚村庄

下载地址（右键另存为）：
- https://raw.githubusercontent.com/xikhar/papertrails/main/screenshots/hero.png
- https://raw.githubusercontent.com/xikhar/papertrails/main/screenshots/village.png
- https://raw.githubusercontent.com/xikhar/papertrails/main/screenshots/village-night.png

**对 GPT 说的话：**
```
我正在做一个纸模立体风格的游戏，主要参考这个项目 papertrails（MIT 开源）的视觉风格。
请仔细观察这些截图的视觉特征：
- 所有物件都像从厚卡纸上裁切、折叠、站立在纸面上的纸片
- 纸片有明显的物理厚度，能看到白色的纸芯截面
- 地面是牛皮纸/宣纸质感的平铺底纸
- 树木、建筑等纸片垂直站立在地面上，投射柔和的阴影
- 整体色调温暖（秋色系：红、橙、绿、褐）
- 景深模糊效果增强了微缩模型的感觉

接下来我会请你生成一些这种风格的素材。
```

### 0.2 给 GPT 看太吾绘卷原版参考

上传 2–4 张原版游戏截图，让 GPT 理解中国古风武侠的色调和意境：

**可用的原版素材（提取到 Mac 后）：**
- `assets/main-menu/` — 主菜单的山水长卷线稿、诗文布局
- `assets/world-map/` — 大地图的省域底图、云朵装饰
- `assets/spine/battle_backgrounds/` — 战斗背景（山岭、江河、庙宇等）
- 或者直接截图游戏画面

**对 GPT 说的话：**
```
这个游戏的题材是中国古代武侠（太吾绘卷），所以在纸模的基础上要融入 20% 的中国传统风格：
- 底纸用宣纸质感（米白色、有纤维纹理），不用牛皮纸
- 装饰元素可以有淡水墨渍
- 色调偏古典温暖：赭石、靛蓝、朱砂、墨色
- 建筑/场景有中国古建筑特征
这些是原版游戏的截图，供你参考整体意境和美术风格。
```

### 0.3 给 GPT 看当前场景预览（如果有）

如果是为特定场景（地区地图、主菜单等）生成素材，上传该场景的开发截图，让 GPT 理解素材在场景中的尺度和构图关系。

## 第一步：生成素材

以下 prompt 在完成第零步之后使用。每个 prompt 前面加一句"按照我们刚才确定的纸模+水墨风格"。

---

### 1. 大地图云影纹理

**用途：** M3-WO2 大地图渲染，云影在地面缓慢飘移
**尺寸：** 1024×1024 px，无缝平铺 | **格式：** PNG alpha

```
按照我们确定的纸模风格，生成一张云影纹理。
- 俯视视角，像从白色厚卡纸上剪下的云朵剪影
- 边缘有纸模的模切锐利感，内部有极淡的宣纸纤维纹理
- 浅灰白色调，半透明（alpha 约 0.3–0.5）
- 云朵面积约占画面 30%，自然散布
- 需要能无缝平铺
- PNG 透明背景，1024×1024 像素
```

---

### 2. 驿路纸带纹理

**用途：** M3-WO2 大地图道路 | **尺寸：** 512×64 px，横向平铺 | **格式：** PNG alpha

```
按照纸模风格，生成一条道路纸带纹理。
- 像从厚卡纸上裁切出的窄纸条，参考 papertrails 截图里小路的感觉
- 顶面是温暖的宣纸米白色，带细微纤维纹理
- 侧面（纸边）露出白色纸芯截面，有明显的纸张厚度感
- 边缘是工艺裁切感，不是手撕的毛边
- 512×64 像素，横向可无缝平铺，PNG 透明背景
```

---

### 3. 菜单背景 — 立体书展开

**用途：** 主菜单背景 | **尺寸：** 2048×1024 px | **格式：** JPG

```
按照纸模风格，生成一张打开的立体书（pop-up book）俯视图，作为游戏主菜单背景。
- 参考 papertrails 的纸张质感：书页是厚实的纸板，有层叠感
- 书脊有折痕和铰链结构
- 两侧页面留白（给 UI 叠加），边缘微微翘起，投射柔和阴影
- 纸面是宣纸质感——米白色底，有天然纤维
- 书页边角可以有淡墨渍或中国传统纹样（回纹、如意）的模切装饰
- 周围是深色木质桌面
- 光线从左上方柔和打来
- 2048×1024 像素
```

---

### 4. 菜单背景 — 卷轴纸模

**用途：** 备选菜单/设置界面背景 | **尺寸：** 2048×1024 px | **格式：** JPG

```
按照纸模+水墨风格，生成一张用纸模工艺还原的中国卷轴，俯视视角。
- 卷轴轴心是圆柱形纸管，两端有裁切精致的纸质装饰
- 展开部分是多层纸叠合——底层厚纸板结构，表面覆盖宣纸
- 卷轴边缘能看到纸层的厚度截面
- 表面干净无文字（留空给 UI）
- 有极淡的水墨山水渲染作为装饰点缀（20%占比）
- 深色桌面背景
- 2048×1024 像素
```

---

### 5. UI 面板底纹 — 宣纸

**用途：** HUD 面板背景纹理 | **尺寸：** 512×512 px，无缝平铺 | **格式：** PNG

```
生成一张宣纸纹理特写，用于游戏 UI 面板背景。
- 温暖的米白色/象牙色
- 表面有天然的纸纤维纹理和细微凹凸
- 贴在纸板上的宣纸，平整但有纤维感
- 偶有极淡的墨点作为水墨点缀，面积不超过 5%
- 色调均匀温暖，无明显图案或文字
- 无缝平铺，512×512 像素
```

---

### 6. UI 面板边框 — 模切纸边

**用途：** 面板/弹窗边框，九宫格切片 | **尺寸：** 128×128 px | **格式：** PNG alpha

```
按照纸模风格，生成一个 UI 边框，用于九宫格切片。
- 正方形画面，中间大面积留空（透明）
- 边框由多层纸板叠合：外层深褐色厚纸板（能看到白色纸芯截面），内层米白宣纸
- 四角有模切的中国传统角花（回纹或如意），微微凸起有阴影
- 边框宽度约占画面 12%
- 整体强调纸板厚度感和模切精致感
- PNG 透明背景，128×128 像素
```

---

### 7. UI 分隔线 — 纸模裁切线

**用途：** 面板内分隔线 | **尺寸：** 512×16 px | **格式：** PNG alpha

```
纸模风格的横向装饰分隔线。
- 像从薄纸板上精密裁切出的窄纸条
- 顶面深褐色，侧面露出白色纸芯截面
- 中央嵌入一个小模切装饰（纸叶或小纸花）
- 两端斜切收尾
- 纸面可有极淡的墨迹纹理
- PNG 透明背景，512×16 像素
```

---

### 8. 纸屑粒子纹理图集

**用途：** 战斗特效 + 场景转场纸屑 | **尺寸：** 256×256 px（4×4 格，每格 64×64）| **格式：** PNG alpha

```
16 种不同形状的纸模碎屑，排列在 4×4 网格中。
- 参考 papertrails 中纸片的质感
- 有厚纸板碎片（能看到截面的白色纸芯和深色涂层）
- 有薄宣纸碎片（半透明，有纤维纹理）
- 有卷曲的纸条
- 形状包括长条形、三角形、不规则多边形
- 色调以宣纸米白和纸板深褐为主
- PNG 透明背景，256×256 像素
```

## 第二步：质检清单

生成后逐项检查：

- [ ] **风格一致**：像 papertrails 截图里的纸模质感，不是平面插画
- [ ] **尺寸正确**：像素尺寸符合要求
- [ ] **平铺测试**：标注了无缝平铺的，在图像编辑器中拼 2×2 检查接缝
- [ ] **透明通道**：GPT/DALL-E 目前可能不支持直接生成透明 PNG，需要后期在 Photoshop/GIMP/rembg 中去除背景
- [ ] **九宫格**：边框素材验证横竖两种九宫格拉伸
- [ ] **色调**：宣纸米白 + 纸板深褐为主，不要出现牛皮纸的黄褐色
