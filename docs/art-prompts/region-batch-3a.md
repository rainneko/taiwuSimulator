## 第 3 步：每张图的自查判据（出完立刻看，不过关就重出，每张最多重出 3 次）

**全部**
- 没有任何文字、字母、数字、印章、签名、水印、边框；石碑、龛、匾一律空白。没有人物和动物。
- 不是照片质感，也不是 3D 渲染质感，而是印在卡纸上的手绘插画。
- **暖色不超过一成**：眯眼看整张，主调是灰蓝、灰青绿、深墨绿、灰白；赭色只在山脚、树干、木构、泥土上。有一大片橙黄、金黄就重出。荒野、峡谷的底纸本来就是土色，例外。
- **饱和度偏低**：石青、石绿是灰调的，不是亮青、亮蓝绿；整体不比基准图更艳。
- 没有金色暖光、夕阳色、窗内或洞里的暖光。

**底纸（#4、第 2 组）**
- 正上方垂直俯视，没有透视、地平线、天空；铺满整幅，上下、左右四边无缝。
- **什么都不立起来**：不画站立的草丛、石块、树冠，没有投影。
- 没有视觉中心，没有单个突出的物体；元素大小相近、均匀散布。整幅只有这一种地表，不画岸线、小路、田埂或任何边界。
- 没有暗角，没有从一边到另一边的明暗渐变；颜色比真实地表更浅、更灰。
- 这一批的十二张底纸加上第一批的五张，缩到 64 像素见方时两两分得开（尤其丘陵 / 原野、石林 / 洞穴、园林 / 聚居地基）。

**立牌与小件（其余）**
- 一个物体（或一组紧挨的物体）完整入画，四周留白约 8%；**最下缘是一条水平直线切边**。
- **不画地面、草皮、底座、圆盘，不画落在地上的影子**，物体下方也没有暗色晕。
- 剪影外缘不额外描白边或黑边；内部纸层的切口可以露一线白色纸芯。
- 背景透明；做不到就用纯品红 #FF00FF 均匀平涂，主体里不能有品红、洋红、亮紫。不要灰白棋盘格。

- 主体立牌缩到 64 像素高、填充小件缩到 **48 像素高**，还能一眼认出是什么。

**逐张特有的**
- **#1 山**：一眼看出从下到上「赭 → 绿 → 青」；峭壁是有棱角的块面；一道白纸云切过山腰；三座峰高低分明。金线如果有，必须很细、暗、断续，画成亮金描边就重出。
