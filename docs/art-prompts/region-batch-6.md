## 这一批要达到什么

1. **山岳要突出**。现在山牌和树一样高，远看分不出山区。这一批出两张大的：**连绵山体**（0.9 格高，横幅）放在山区里面的格子，**主峰**（1.5 格高，竖幅）一片山区只放一座。这两张比别的立牌大得多，画幅也放大了。
2. **地标不再反复出现**。桃源入口、土地庙、水车、渔船以后一片地形只放一个；桃源、农田、湖泊的普通格子需要各补一张普通立牌。
3. **还是旧配色的图按青绿重画**：橙色树干的杉树、几个小件、四张底纸。
4. 第三批 3a 里第 4、5 组没出的图（驿站、废墟、三种奇遇标记、五个小件）一起出。
5. **小件第一次用拼图**：8 个立牌小件画在一张 4×2 的拼图上，2 个平放件画在一张 3×2 的拼图上，流水线会自动切开。

一共要出 **17 张图**（单张 15 张 + 拼图 2 张），对应 25 个素材。

## 第 1 步：出图顺序

1. **第 1 组**。先出主峰，再出连绵山体（附主峰的成图，叮嘱「山石画法与它一致」）。**画幅按表里的横幅 / 竖幅出**，不要出成正方形；主峰是全场最高的东西，要挺拔，但底部够宽、站得住。
2. **第 2 组**、**第 3 组**。各附青绿基准；驿站、废墟、孤亭再附 `house.tile.0`。
3. **第 4 组拼图**。先出立牌拼图，再出平放拼图。**附录里每张拼图是一整条 prompt，一次出一整张**：
   - 画幅 1536×1024 横幅。格线不画出来，格与格之间只有背景。
   - 每格一件，按 prompt 写的「约占格高几成」画，同一行的底边在同一条水平线上。
   - **任何一件都不能碰到格线或和邻格连在一起**，这是切图的前提。
4. **第 5 组底纸**。附两张青绿底纸；四边要能无缝平铺。

同一组尽量在同一个对话里连续出。对话太长或风格开始漂移时，新开对话，先重做第 0 步、贴回已通过的图再继续。

## 第 2 步：保存

- 单张存为 `assets/art-source/region/batch6/<artKey>.png`，文件名严格等于表里的 artKey。
- 拼图存为 `assets/art-source/region/batch6/sheet.<拼图名>.png`（例如 `sheet.b6s1.png`）。**不要自己切开**，流水线会切。
- **拼图里某一件画坏了**：单独出这一件，存为 `batch6/<artKey>.png`，它会优先于拼图切出的那张，不用整张重出。
- 重出时直接覆盖同名文件；想保留旧版本就另存为 `<名字>.v1.png` 等。这个目录在 `.gitignore` 里，不要 `git add`、不要 commit。

## 第 3 步：每张图的自查判据（出完立刻看，不过关就重出，每张最多重出 3 次）

**全部**
- 没有任何文字、字母、数字、印章、签名、水印、边框；碑面空白。没有人物和动物。
- 背景透明或纯品红；立牌最下缘是水平直线切边，不画地面、落影和下方的暗色晕。
- 暖色不超过一成，饱和度不比基准更艳。

**第 1 组**：主峰缩到 128 px 高还是一座挺拔的峰，不是一团；连绵山体中间高、两侧低，三四个峰头分得开。不要雪顶。
**第 2 组**：稻草垛是灰褐的干草色，不是金黄；三张都比第一批的地标简单、矮。
**第 3 组**：柏树不是卡通圣诞树、树干不是橙红；四种野外地点缩到 96 px 高能互相分开。
**第 4 组拼图**：格数、顺序和附录一致；没有一件碰到格线；同一行底边齐平；空格里什么都没有。
**第 5 组**：3×3 平铺后看不出接缝；暗渊不是纯黑或藏青，石林不像雪地，聚居地基不像整齐的石板广场。

## 第 4 步：跑流水线

```bash
PREVIEW=0 bash tools/art/batch.sh batch6
```

「错误」按说明重出；「警告」目视确认后保留并在报告里写一句。拼图报「越格」「空格」：重出整张拼图，或只单独补出那一件。
