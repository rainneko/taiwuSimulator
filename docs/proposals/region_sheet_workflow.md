# 小件拼图出图（2026-11-25 用户定）

> 地区场景美术专员。小件不再一张一张出，而是让 GPT 把同类的若干件画在一张拼图上，流水线自动切开。

## 哪些件用拼图

只有游戏里像素需求小的件：填充小件 `filler.*`、前景小件 `loc.prop.*`、地面散件 `ground.piece.*`。
房屋和地形立牌（要 400 px 以上）照旧单张出。

| 版式 | 画幅 | 格 | 用于 |
| --- | --- | --- | --- |
| `grid43` | 1536×1024，4 列 3 行 | 384×341 | 一般立牌小件，9–12 件 |
| `grid42` | 1536×1024，4 列 2 行 | 384×512 | 立牌小件 7–8 件（不留整行空格） |
| `grid32` | 1536×1024，3 列 2 行 | 512×512 | 平放件；不满半张（5–6 件）的立牌小件 |
| `grid22` | 1536×1024，2 列 2 行 | 768×512 | 3–4 件 |
| `grid21` | 1536×1024，2 列 1 行 | 768×1024 | 1–2 件（不留空格） |
| `wide24` | 1024×1536，2 列 4 行 | 512×384 | 很宽的件（竹篱、覆瓦墙） |

## 分组规则（`tools/art/sheet_plan.py`）

1. 立牌（正面看）与平放件（俯视）不进同一张。
2. 每件按游戏里要的像素（高 × 768 px/格）挑能装下的版式；都装不下就单独出。
3. 按材质（石 → 草木 → 竹木 → 地面）、同材质从高到矮依次填格；拼图之间尽量在材质交界处切开。
4. 同一张按同一比例画：比例取「最占地方的那件刚好填满格子可用区」，并保证不低于游戏里的像素密度；每件在 prompt 里写「约占格高几成」。

```bash
python3 tools/art/sheet_plan.py filler.bush.0 filler.log filler.stump --prompts   # 打印分组、@sheet 行和每张拼图的完整 prompt
```

prompt 的风格段与 `region.md` 单张出图完全相同；各格内容取 `region.md` 里同名块的「内容」段，「避免」句合并去重。

## 批次列表与流水线

批次列表里一行一张拼图：

```
@sheet s1 4x3 filler.rock.1,filler.rock.0,filler.bush.0,…,-,-     # 从左到右、从上到下；空格写 -
```

- 出图方把拼图存为 `assets/art-source/region/<批次>/sheet.s1.png`（透明底或纯品红底）。
- `batch.sh` 先跑 `split_sheet.py`，切到 `<批次>/sheet-cut/<artKey>.png`，然后照常逐张检查。`pack_region.py` 也认这个目录。
- 某一件画坏了：单独补出存为 `<批次>/<artKey>.png`，它优先于拼图切出的那张，不用整张重出。

`split_sheet.py` 每格检查：空格（错误）、物体碰到格线（错误，可能与邻格粘连）、和同张其他件比例偏差超过 30%（警告）。

## 验证

- `tools/art/tests/test_sheet.py`：11 条，包括合成拼图的切分、越格、空格、比例，以及分组的版式（按件数选版式）、密度和材质连续。
- 用 12 张已验收的小件按规划摆成一张品红底拼图，切开后全部通过 `key_alpha`（只有旗杆两根分开、小花瓣散开这类图本身的警告）。
