> 纸模立体书（papercraft diorama）风格的游戏美术素材，质感以随附的参考截图为准：每个物体是一张从厚卡纸上模切下来的纸片，纸片正面印着一幅手绘插画——水粉、水彩的笔触质地，带装饰性的图案细节（叶片纹样、瓦垄、木纹、山石的皴擦），轮廓与结构用干净的深色细线勾出，纸面有细微的宣纸纤维纹理；树冠、屋顶、山石可以由两三张纸片前后叠贴，层间有一道细窄的接触阴影，切口露出一线白色纸芯。造型概括、端正古朴，剪影干净利落。**配色是略低饱和的青绿山水：以灰蓝的石青、灰青绿的石绿、深墨绿的松墨、墨色与纸白为主；赭石只用在山脚、树干、木构与泥土；朱砂只在柱子、灯笼这类小处点一下；暖色合计不超过画面的一成，不要秋天的橙黄调。**只在局部用少量淡墨晕染、点苔或枯笔皴擦作点缀（约占画面两成），不要大面积水墨渲染。淡墨只用来晕染和点苔，不要形成任何像文字、符号或印章的笔画。**光是清冷的散射光，不要金色的暖光、夕阳色，也不要窗里透出的暖灯。**画面里没有任何文字、字母、数字、印章、签名、水印、边框，也没有人物和动物。**避免：温馨的欧式农舍、谷仓、风车、草垛、南瓜、白色栅栏、童话小镇、圆鼓鼓的山丘和光滑的草坡、秋天的橙黄色调、金色夕阳、窗内暖光、Q 版造型、日式鸟居与日式石灯笼、霓虹光与发光粒子。**

## C. A/B 怎么做

**主管的方案**：新配色段 + 避免项重出 4 张（松、三峰山、茅屋 A、原野底纸），和现有同位图各拼近档、中档。

**我的调整：3 张重出 + 其余全部运行时调色，比 4 张重出更省，也更公平。**

1. **原野底纸不重出**。附图 `compare-runtime-grade.jpg` 是在现有近档预览上做的色相选择性调色（橙黄降饱和、草绿推向青绿、整体略冷）：底纸、草、填充小件、地面散件都能拉到青绿调，所以重出底纸看不出新东西。
2. **调色拉不动的是内容与山的渐变**：茅草顶、圆冠橙树调完只是变成米黄，还是田园感；山牌也调不出赭 → 绿 → 青。所以只重出这三张：**`mountain.0`（三峰）、`woods.0` 改松、`house.cottage.0`**（或 `loc.village.0`，取决于 A/B 预览开不开 `--houses`；我建议开，因为 batch2 等的就是它）。
3. **B 边 = 3 张新图 + 所有其余素材在载入时做同一套调色**。只换 4 张、其余几十张仍是暖色的话，B 边一屏里大部分还是橙的，用户会低估青绿的效果。
4. 顺手把 §A.8 的 `--cliff-walls`（赭色岩层侧壁）做成第三列，一次问完。
