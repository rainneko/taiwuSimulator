## 7. 同一格 / 相邻格不重复同一房屋 artKey

- **同一格不重复：已采纳、已落地。** 工单 §3.12.3 约束 7：有没用过的款时不重复；只能重复时，两栋相同的不相邻。
  - Python 参考实现与测试已在 `preview_grid.py`，第二批房屋实测通过。
  - **TS 的同步改动是 region-scene 的**，已经告诉过它；同一时间它还要同步约束 8（殿阁放不下时不空格）。
- **相邻格不重复：不采纳。**
  - 现在每格的房屋只取决于本格（哈希 + 本格道路），可以单独重建、单独测试。跨格去重会让一格的摆放依赖邻格，必须按固定顺序生成，改一格就会连带改邻格。
  - 聚居格本来就很少相邻。第四批出完后每种房屋有 2–3 款，按格哈希选款，相邻两格撞款的概率已经很低。
  - 真成了问题，可以改成「邻格用不同的选款种子」这种不引入依赖的做法。
