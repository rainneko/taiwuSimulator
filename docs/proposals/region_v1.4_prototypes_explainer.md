# 地区场景 v1.4 三项原型：河、过渡带、群山海拔（给用户看的一页说明）

> 地区场景美术专员，2026-11-24。对比图在 `art/region/review/`：`compare-rivers.jpg`、`compare-ecotones.jpg`、`compare-ridges.jpg`、`compare-all.jpg`（三项全开）。
> 新增的素材现在都是**占位**：桥、汀步、睡莲、码头是程序画的色块，山麓丘暂时用现有山牌图压扁代替。样子不代表最终美术，只看位置、密度、层次。你选定方向后再写 prompt 出图。
> 群山那张为了看清山体，把地形里山的比重加了一倍；其余三张用的是平常的五种地形。

## 1. 河：沿格边流，不占格（`--rivers`）

- 河走两格之间的交界线，**格子本身不变**：棋子站位、地名、房屋空地都不受影响，15×15 的玩法格不用改。
- 源头在山脚（山体外沿的一个角），流进湖或流出地图；不上山、不做瀑布。每个地区 0–2 条。
- 河宽从上游 0.06 格渐宽到下游 0.14 格（不超过道路）。两边地形相同的边上有蛇曲，地形不同的边上不弯（免得和撕纸交界打架），转角圆化半径 ≤ 0.15 格。
- 河中线离任何格心至少 0.28 格以上，所以棋子周围永远有空地。
- 第一期不切地面：一条水面纸带，两岸一道纸芯白边，靠光一侧的岸往河里投一点影。
- 道路跨河处放桥：一般是**木板平桥**（平贴在地上，任何方向都行）；道路横向（与屏幕水平）且挨着城镇时放**石拱桥**（立牌）。没有路的地方每隔 3–5 格放一组**汀步石**。
- 湖岸的岸边件（芦苇、石块）沿河岸也撒，密度是湖岸的一半。

## 2. 格间过渡带（`--ecotones`）

两种地形相接处不再只有一道撕边。现在按六大类（水、林、石、旷野、湿地、田）查表，在交界线**本侧**的窄带里撒过渡件，只用纸片，不做颜色渐变：

| 相接 | 做法 |
| --- | --- |
| 林 ↔ 旷野 / 田 / 湿地 | 林缘：靠交界 0.2 格内的树牌缩到 0.75 倍；旷野一侧 0–2 丛灌木、蕨、树桩 |
| 山 ↔ 低处 | 山脚散石：只放在低的一侧、贴着侧壁脚 |
| 陆地 ↔ 湖 | 原来的岸边件；湖一侧 0–2 片睡莲（平贴）；邻湖的聚居格加一个小码头 |
| 旷野 / 田 ↔ 沼泽 | 芦苇、草簇；沼泽一侧偶尔一个积水洼（平贴） |
| 田 ↔ 聚居 | 一段篱笆 |

过渡件计入每格 8 个填充小件的上限，聚居格里不撒、房屋扇形不挡。

按现在的密度，近档的变化**比较含蓄**：最明显的是邻湖村口的码头、湖边芦苇和林缘的灌木，其余要细看才分得出。这也是下面第 3 个问题要你定的。

## 3. 群山海拔（`--ridges`）

- **鞍部**：山体内部随机有一些格降一层（只降不升，外圈始终 +1 层，相邻格最多差 1 层，封顶 +3），大山不再是同心圆的金字塔。
- **山牌分档**：靠镜头的两行和外圈放**矮的山麓丘**（新素材，约 0.3 高）；中层放现在的 `mountain.0`；高层放 `mountain.1`；每条山脉一个**主峰**（单独一张、最高）。从镜头看，山由前往后、由外往内逐级升高。
- **山脊线**：每条山脉算出主走向，山牌沿走向排成一两条脊线，而不是格内随机。
- 现有两张山牌、它们的 prompt、高度、宽高比都不动。
- 看图：中档里前排是一溜矮丘，往后才是成排的山牌，读得出「由低到高」；远档的变化主要是山前那一圈矮了。主峰 0.5 与 0.6 在中、远档差别很小，只有主峰正好不在前两行时才看得出来。

## 需要你定的三件事

1. **河挡不挡路？** 现在只是画面：棋子可以直接走过河。要不要改成「过河必须走桥或汀步」？这是玩法规则，建议先只做视觉，以后再说。
2. **主峰多高？** 对比图里有 0.5（与现在的山牌一样高）和 0.6 两种。0.6 更有「一峰独秀」的感觉，但会挡住后排更多东西；从图上看两者差别不大，我倾向 0.5，省一张主峰专用图。
3. **过渡带多密？** 现在的密度是：林缘 0–2 丛、山脚 1–2 块、湖边睡莲 0–2 片、积水洼 0–1 个（每条交界边）。你觉得太密、太稀还是正好？

另外，水面要做出「质感」，可以参考你另一个项目 nero_rome 里的多层水面做法；需要的话我去读那几个分支。
