# 提案：格间过渡带、蜿蜒水路与小桥、群山海拔（M3-WO3 v1.4 候选）

> 地区场景美术专员，2026-11-24。用户原话：「隔了格可以有一些什么水，小桥，等等的渐变区域，还有水路可以蜿蜒现实一点，还有群山你打算怎么做海拔？你都要和主管会话好好讨论，你可以让他去做，也可以让他请 subagent opus 去做。」
> 现状：交界只有扭曲的撕纸边（`gWarp` 0.16）+ 湖岸 0.12 宽的浅水带与岸边件（`SHORE`）；水只有湖泊格（`WATER_TERRAINS = ("lake",)`），没有河；山岳靠层号 +1..+3（BFS 深度）抬层，山牌一律 0.5 高、每格 1–2 张。

## A. 河走格边，不占格（核心建议）

**河不做成一种地形格，而是沿格与格之间的边流**（扭曲后的格边）。理由：棋子站在格心、地名在格心，河占格会和玩法、房屋空地冲突；走格边正是用户说的「隔了格」，而且 15×15 的玩法格完全不用改，河是纯装饰层 + 一条移动规则（过河要有桥或渡口，可先只做视觉）。

1. **生成（纯函数 `rivers.ts`，种子决定）**：在格点图（(N+1)² 个顶点、格边为图的边）上找路径。源头 = 山岳格的一个角（优先层号最高的山）；终点 = 湖泊格的边或地图外沿。代价 = 顶点海拔（相邻格层号的平均）× 上坡惩罚 + 拐弯奖励（连续两段同向加罚，防止笔直）+ 与道路平行的惩罚。每个地区 0–2 条，乡村地区（10×10）至多 1 条；有湖的地区优先有一条入湖。
2. **蜿蜒**：格点路径 → Chaikin 两次 → 沿法线加正弦曲流（振幅随下游距离从 0.04 增到 0.12，波长 0.6–1.0 格，相位由种子定）→ 再走同一个 `gWarp`，让河和撕纸交界一起弯。宽度从源头 0.06 渐宽到入湖 0.16；交汇处取两支宽度平方和开根号。约束：曲流后离格心至少 0.28（不压棋子与房屋空地），曲线自交就降振幅重算。
3. **成形**：河道是一条下陷的纸带，复用地形纸层的做法：顶面切开、两岸各一道 −0.5 层的侧壁（纸芯白），河面是一张水纹纸带（UV 沿河长平铺，同道路的挤带做法），岸边 0.06 宽浅水带。河流入湖处与湖岸浅水带融合。
4. **桥与渡**：道路（`roads.ts` 的路径）跨过河边时放桥：路是土路放小木平桥，城镇附近放石拱桥；没有路的地方每条河隔 3–5 格放一组汀步石（仅装饰，不改移动）。桥是立牌（横跨方向与河垂直，面朝镜头的那一面画桥侧面）；桥面高于两岸 0.02，道路纸带在桥两端断开、桥牌压住断口。

## B. 交界过渡带（ecotone）

现在两种地形相接只是一道撕边，两侧的布置各管各的。改为**按地形对查表，在扭曲后的交界两侧 0.1–0.25 格的带里加过渡件**，并让两侧的填充密度随离交界的距离渐变：

| 地形对 | 过渡做法 |
| --- | --- |
| 林地 / 密林 ↔ 原野、农田 | 林缘：树牌密度在离交界 0.3 格内从 100% 降到 30%，越出交界 0.15 格散 1–2 棵孤树 + 灌木；林下地面散件（落叶）跨边延伸 |
| 山岳 ↔ 任何非山 | 山麓：非山一侧 0.2 格内放土丘、碎石（填充件 rock、tuft），山一侧最外圈只放矮的山牌（见 C 的分档） |
| 湖泊 ↔ 陆地 | 现有浅水带 + 岸边件；加小码头 / 渡口（聚居格邻湖时）、浅水里 0–2 丛芦苇、睡莲浮叶（平贴散件） |
| 沼泽 ↔ 湖泊 / 原野 | 芦苇、积水洼（平贴）跨边 0.2 格；沼泽与湖之间不撕边，改成浅水带渐变 |
| 农田 ↔ 聚居 | 田埂小路、篱笆段（前景件 fence）沿交界 |
| 石林 / 洞穴 ↔ 其他 | 碎石、孤立小石笋跨边 |

实现上就是布置函数（`dressing.ts`）多一个「交界带」通道：对每条异种格边，按表在带内撒件（与河、路的中线保持 0.08 间隙），占用原来两侧格的一部分填充名额，总数不超过 §3.6 的每格上限。

## C. 群山的海拔

现在：层号 = 到非山格的 BFS 深度（+1..+3），每层 0.05（或 0.08）厚的等高线叠纸；山牌一律 0.5 高。建议改成「**层号 + 山牌分档 + 山脊朝向**」三件事，叠纸负责地面海拔，山牌负责剪影海拔：

1. **层号更自然**：BFS 深度之外加一个低频噪声（±0.5，取整），让大山体里出现鞍部和主峰，不再是同心圆的「金字塔」；封顶仍 3（`levelStep` 0.08 时总高 0.24 格）。山体里层号最高的 1–2 格标为主峰。
2. **山牌按层号分档**：外圈（层 1）用矮山 / 丘牌，高约 0.3；中层（层 2）0.4；主峰（层 3）0.5–0.6，配一条横缠的纸云（两成水墨点缀）。这样从镜头看，山体由前到后、由外到内逐级变高，读得出「群山」而不是一片一样高的山牌。需要补 2 张素材：`terrain.standee.mountain.2`（低矮的山丘群，高 0.3）与 `terrain.standee.mountain.3`（主峰，高 0.6），层 2 沿用现有两张。
3. **山脊朝向**：对每个连通的山体求主轴（格心坐标的主成分），同一山体内山牌的摆放沿主轴错开排成一两条山脊线，而不是格内随机；靠镜头一侧（+z）的格只放矮档，避免挡住后面的高峰和棋子（沿用房屋的「不挡棋子」扇形）。
4. **远档**：远档一格约 2–3 个层厚像素，海拔主要靠山牌分档读出；层号影响山牌的阴影长度（越高投影越长，已由真实阴影自然给出）。
