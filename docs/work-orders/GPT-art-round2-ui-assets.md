## 2. 逐个出图

每项单独生成，按各节指定的参考图传图。Prompt 中的最终像素为交付规格。生图工具输出其他尺寸时，可先生成同构图的高分辨率源图，再做裁切、缩放、alpha 清理和平铺封边。

### 1 · 大地图云影

成品 `assets/paper-ui/map/cloud-shadows.png` · 1024 × 1024 · RGBA PNG · 双向平铺。参考 P2、T2。

```text
制作一张原创纸模地图专用的云影贴图。参考图一用于纸张模切质感，图二用于验证叠到太吾线描地形上之后，山脊、河流和标记仍可读。只画云形，不画地图和场景。严格垂直俯视，正方形，真透明底。五至七团细长、疏密不一的浅灰白云影，顺地面自然横向延展。云团来自一片片手工模切薄卡纸的轮廓，主峰和小云瓣不对称，避免同一朵模板缩放复制和卡通胖云。轮廓有准确的切边，局部一丝极淡的宣纸纤维，云心近乎平坦。不要立体云体、投影、外发光或绕边白线。云形面积约 30%，四边保持适度净空，双向无缝重复。成品 1024×1024 RGBA，云形主体 alpha 0.30–0.50，背景 alpha 0。RGB 中性浅灰白，供地图渲染染成暗影。
```

### 2 · 驿路纸带

成品 `assets/paper-ui/map/road-ribbon.png` · 512 × 64 · RGBA PNG · 横向平铺。参考 P2、T2。

```text
制作原创大地图驿路用的连续纸带纹理。借鉴参考中纸模路面与地面的断面构造，将道路抽象为一条连续、水平、等厚的窄卡纸带。真透明底，纸带穿出画面左右边，相对两端同高、同厚、同色，纸带和纸芯都不收尖。正上方微带侧面可见度；暖象牙、低对比的细宣纸纤维；下边是一条清晰、薄而浅的纸芯截面，靠它表现厚度。纸带上下有透明余量，羽化只在最外 1–2 像素，主体不透明。切边整洁，有少量轻微加工痕迹，不出现卷曲、虚线、道路线、土石、墨线或物件。最终裁切范围里只保留同一条路的连续中段。512×64 RGBA，左右无缝平铺。
```

## 3. 质检与覆盖

- 比对纸模基线。菜单有可辨识的纸板厚度、折叠结构和层间阴影，标题与按钮区留白。贴图的纹理缩小后仍可用。
- 核对八张的编码、像素和通道。云影覆盖约 30%，中心 alpha 0.30–0.50。透明区用明暗双色底检查残雾和锯齿。
- 云影、宣纸拼成 2×2；驿路拼成 3×1。比对边缘像素并查看拼接预览。
- 模切框按 26 px 做横宽和竖窄预览；纸屑的 16 个格子逐个检查透明边和碎屑独立性。
- 在临时目录暂存成品，验收过的成品按同一路径覆盖旧图。最终向交接人提供此工单、八个相对路径和实测结果。
